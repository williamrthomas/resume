## Pattern codification I've actually done

The "codify repeatable patterns" line in the JD is real for me, not aspirational.

- **Pop Health support model (2017).** No existing support structure. Built case ops, knowledge base, runbook for a complex data operation under heavy product churn. The model is still in use.
- **Enterprise data product operationalization.** Inherited a raw data dump that engineering had productized without building the operations side. Built support, ops, integration into the rest of athena, and turned it into a real client offering.
- **Federated AI operating model (2025).** Stood up federated teams of AI builders across the zone so adoption ran on multiple fronts simultaneously rather than one slow front. The pattern survives even when individual project owners rotate.
- **Governed analytics platform (2025).** Shared SQL models, semantic tests, validation gates, and consumer-facing data contracts. Downstream consumers get a stable surface instead of a moving target.
- **Local-first analytics packaging.** Warehouse → Parquet → DuckDB pipeline with manifests, validation gates, provenance, and launch flows. Turns governed data into portable, versioned stakeholder packages.
